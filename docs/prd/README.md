# Product Planning Notes

This directory is reserved for approved product requirement documents. It does
not currently replace the issue tracker or the authoritative platform docs.

Use these current references when planning work:

- [Platform capabilities](../product/platform.md)
- [Roles](../product/roles.md)
- [User flows](../product/flows.md)
- [Mission and context](../project-overview/mission.md)

New requirement documents should state their owner, status, acceptance criteria,
dependencies, and links to the implementing issues. Do not place credentials,
private member data, or copied production exports in a product document.
