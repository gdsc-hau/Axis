# GDG HAU Docs

This documentation site is the living reference for the GDG HAU ecosystem.

It covers the product intent, repo structure, app surfaces, shared packages, Supabase data model, and the operational runbooks needed to work on the platform safely.

## What to use this for

- Understanding the purpose of the platform
- Finding the right app, package, or route
- Reading the Supabase schema and migration notes
- Following local development and deployment steps
- Keeping contributor guidance in one place

## Source material

The initial content is derived from the existing repository README, the source-of-truth notes, and the docs folders already present in the repo.
