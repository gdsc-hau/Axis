Database Schema Overview¶

The GDG HAU Axis platform relies on a robust relational PostgreSQL database hosted on Supabase.

The schema is designed to ensure referential integrity (using foreign keys and cascading deletes) and to handle data changes safely (using automatic updated_at triggers).

High-Level Domain Model¶

The database can be conceptually divided into four domains:

  1. Identity & Profiles
  2. Core tables defining who a user is.

  3. Tables: members, member_credentials, id_qr_codes. Profile fields are stored on members.

  4. Events & Engagement

  5. Tables tracking what is happening and who is attending.

  6. Tables: events, event_attendance.

  7. Gamification & Rewards

  8. Tables handling the economy of GDG HAU.

  9. Tables: points_ledger, redemptions, badges, member_badges.

  10. System Logs & Notifications

  11. Tables handling auditing and member messaging.
  12. Tables: notifications, audit_logs, verification_logs, app_settings.
