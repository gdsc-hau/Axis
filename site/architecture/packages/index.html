Shared Packages¶

The repository includes shared modules for authentication, database access, events, certificates, badges, points, marketplace logic, PWA helpers, UI, and shared types.

Observed packages¶

  • auth: session, roles, and guard helpers
  • db: client, server, and admin Supabase access
  • events: Luma sync, RSVP, attendance, and sync helpers
  • certificates: certificate templates, PDFs, email, and storage
  • marketplace: items, redemption, and fulfillment logic
  • points: scoring and award logic
  • pwa: install and service worker related helpers
  • ui: reusable presentation components
  • contracts and types: shared contract and type definitions

These packages are the right place to document reusable domain logic and cross-app contracts.
